Tune it from the prompt.

Everything lives under /pixelstack. Settings persist across sessions, so pick an accent once and it sticks.

Accents take any of the five presets or your own hex color. Spooky mode is on by default; the sound is off until you ask for it.

~/code · claude
# turn the theme on or off
/pixelstack on
/pixelstack off

# swap the accent: purple · pink · cyan · green · orange · #hex
/pixelstack accent pink
/pixelstack accent #FF5555

# bat avatar and vampire words (on by default)
/pixelstack spooky off

# organ sting when a turn finishes (macOS, off by default)
/pixelstack sound on

# what's on right now
/pixelstack status

Invite it in.

A vampire can't enter unless invited. Thirty seconds, three ways.

  1. At the prompt of a terminal session, run:
    /plugin install pixelstack --marketplace rossedman/claude-dracula
  2. Answer y to add the marketplace.
  3. Pick a scope. That's it. Try /pixelstack accent pink.
  1. Run:

FAQ

Does it change my terminal's colors?

No. The mod colors its own elements: bubbles, cards, tool rows, the working line. For the full look, pair it with Dracula for your terminal.

Can I get the default rows back?

Anytime. /pixelstack off turns the theme off, and expanded views (ctrl+o) always show the full default rows.

I want the colors but not the bats.

/pixelstack spooky off swaps the bat for a four-point spark and puts the usual working words back.

Does it work in the mobile app?

The Claude mobile app runs the mod's commands, but it doesn't currently show the restyled rows. The organ sting plays on macOS only.
